STUDYPILOT — Tech-style starter website

Open index.html in a browser to preview the bilingual English/French homepage.

This is a static preview, not a functioning store:
- No checkout or payment processing is connected.
- Courses are marked Coming Soon and should be created before being advertised as available.
- Do not upload paid course files publicly before secure delivery is configured.
- Hosting may have a free tier; payment providers can still charge fees.
- Because the project owner is under 18, a parent/legal guardian should help review platform age rules and handle seller/payment account setup and applicable obligations.
