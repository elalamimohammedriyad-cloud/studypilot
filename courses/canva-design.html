Graphic Design with Canva

Apply visual hierarchy, typography, colour and layout principles to create polished communication materials.

Beginner3 hoursEN / FR

Course curriculum

Work through the modules in order. Each lesson includes a practical idea to apply.

Module 1: Design principles

Visual hierarchy

Make the most important information easiest to notice through size, position and contrast.

Typography and colour

Use a small, consistent type system and a limited palette with sufficient contrast.

Module 2: Create useful layouts

Grid and spacing

Align elements, leave breathing room and repeat spacing rules for consistency.

Images and assets

Choose relevant visuals and check licences and usage rights before publishing.

Module 3: Export and review

Choose the right format

Select dimensions and file formats based on the destination, such as social, print or presentation.

Quality checklist

Check spelling, alignment, contrast, readability and consistency at final size.

Practical project

Design a small brand kit: a simple logo concept, two social graphics and a one-page style guide using original or licensed assets.
