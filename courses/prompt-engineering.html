Prompt Engineering

Write clear instructions, structure complex requests and evaluate AI outputs systematically.

Beginner to intermediate4 hoursEN / FR

Course curriculum

Work through the modules in order. Each lesson includes a practical idea to apply.

Module 1: Prompt fundamentals

Goal and context

Describe the outcome, intended audience and relevant background before requesting an answer.

Constraints and format

Specify length, tone, language, boundaries and the structure you want.

Examples

A short example can clarify the style or format. Use original examples and avoid sharing confidential material.

Module 2: Advanced techniques

Break down complex tasks

Split a large task into stages: plan, draft, review and final output.

Iterate with criteria

Evaluate accuracy, relevance, clarity and completeness, then request targeted changes.

Module 3: Prompt testing

Build a prompt library

Save reusable prompts with a title, purpose, variables and a note about when not to use them.

Compare outputs

Test the same prompt more than once and compare results against a rubric rather than relying on one response.

Practical project

Create and test a reusable prompt pack for a safe, useful workflow. Include three prompts and a short evaluation rubric.

Knowledge check

1. What is the best first step?
2. How should you check quality?
3. What is a responsible habit?
